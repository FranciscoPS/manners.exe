# Mecánicas

# Movimiento

El movimiento del jugador es constante y se puede realizar en cualquier dirección siempre y cuando sea horizontal (por ahora).

# Destrucción del entorno

El jugador tiene la opción de caminar hacia los edificios para destruirlos y tener la oportunidad de obtener monedas para la tienda.

# Tienda

Dentro de los niveles hay un edificio rodeado por una orbe de luz, al principio verde pero una vez se deshabilita roja, el cual funciona como una tienda.

Dentro de esta tienda, el jugador va a poder invertir algunas de sus monedas para comprar mejoras premium. Conforme el nivel de las mejoras especiales suba, el costo para subirlas en la tienda también  se verá incrementado.

# Selección de mejoras por nivel

Cada vez que el jugador suba de nivel, en la pantalla aparecerán un conjunto de 3 opciones de estadísticas base que puede elegir para aumentar.

Dentro de estas elecciones existe la única manera de recuperar vida (POR EL MOMENTO).

# Recolección de recursos

Para que el jugador recoga los drops que sueltan los enemigos, símplemente tendrá que acercarse a ellos. La estadística del Rango de Recolección (Imán) es la que definirá el radio desde el cual el jugador puede recolectar los recursos del suelo.
